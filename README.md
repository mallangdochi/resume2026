# 💻 정종범 개인 포트폴리오 웹사이트 (Jongbeom Portfolio)

영상 편집 기술과 모션 그래픽 요소를 웹 디자인에 녹여낸 반응형 인터랙티브 포트폴리오입니다.

단순한 자기소개나 텍스트 나열을 넘어, 방문자가 직접 클릭하고 경험할 수 있는 동적인 요소(룰렛, 3D 플립 등)를 한 페이지에서 직관적으로 확인할 수 있도록 제작했습니다.
